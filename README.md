# Civil Service Exam Practice

A Khmer-language practice website for candidates preparing for Cambodia's civil-service clerk exam.

## Pages

- `index.html` — study overview and suggested routine.
- `daily-quiz.html` — 12 selectable lessons with 72 practice questions. Scores and completed lessons are stored in the browser.
- `sang-sopheak-logo.jpg` — portrait logo used in the site header.

No build step is needed. Open `index.html` in a browser to use the site locally.

To publish with GitHub Pages, open the repository's **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.

The questions are practice material, not official exam questions. Check current exam requirements and dates with the Ministry of Civil Service.
